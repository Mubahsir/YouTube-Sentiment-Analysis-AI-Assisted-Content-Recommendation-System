# YouTube Sentiment Analysis & AI-Assisted Content Recommendation System

## Included
- `YouTube_Sentiment_Analysis_Project.ipynb`: Complete Google Colab notebook.
- `README.md`: Setup and run instructions.
- `requirements.txt`: Python dependencies for local use (Colab notebook installs them itself).
- `PROJECT_OVERVIEW.md`: Scope, methodology, limitations, and deliverables.

## Run in Google Colab
1. Upload/open the `.ipynb` notebook in https://colab.research.google.com/
2. In Google Cloud Console, create a project and enable **YouTube Data API v3**.
3. Create an API key.
4. In Colab, open **Secrets (🔑)** and add `YOUTUBE_API_KEY` with the API key value. Enable notebook access.
5. Run notebook cells from top to bottom.
6. Enter the brand name or YouTube search phrase when prompted.
7. At the end, download `youtube_sentiment_results.zip`.

## Important
The project is configured for a brand/query you enter at runtime because no specific brand was provided. No real comments or empirical findings are included in this starter package: run it with your own API key to generate real results. API quota and comment availability may limit collection below 2,000 comments. Sentiment predictions, especially for Roman Urdu, should be manually validated before reporting them as research findings. Use data responsibly and do not expose personal information from comments.
